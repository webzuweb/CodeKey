# Диагностика CodeKey

## Как получить файл

1. Откройте **Настройки**.
2. Перейдите в блок **Диагностика и журналы**.
3. Нажмите **Отправить журнал для отладки**.
4. Выберите приложение, через которое хотите передать файл, либо сохраните его в «Файлы».

Имя файла:

```text
CodeKey-diagnostics-2026-08-29T12-34-56-000Z.jsonl
```

Формат JSON Lines: каждая строка — отдельное событие с UTC-временем, уровнем, именем события и безопасными диагностическими полями.

## Что полезно сообщить вместе с файлом

- Android или iPhone;
- модель телефона и версию ОС;
- точный шаг, на котором возникла ошибка;
- воспроизводится ли ошибка повторно;
- цвет/состояние BLE и USB;
- приблизительное время ошибки.

## Какие события записываются

- инициализация приложения и загрузка настроек;
- выдача разрешений камеры/Bluetooth;
- добавление и удаление снимка;
- начало/завершение/ошибка OCR и размер файла;
- BLE status, scan, connect, auth и GATT operations;
- число DLP-срабатываний по категориям;
- API provider, host, model, HTTP status и длительность;
- валидация JSON-ответа;
- размер job, число операций и прогресс печати;
- Flutter framework/platform/zone errors.

## Что не должно записываться

- фотография;
- исходный OCR-текст;
- код из ответа модели;
- запрос пользователя;
- API key;
- setup key;
- Authorization header;
- приватный ключ;
- JWT и bearer-токен.

Встроенный sanitizer также маскирует типовые credential-последовательности в текстах исключений. Полной гарантии для произвольных ошибок сторонних SDK дать нельзя, поэтому перед отправкой откройте JSONL как текст и проверьте его.

## Ротация

- основной файл ограничен примерно 1 МиБ;
- хранится до трёх архивных файлов;
- кнопка **Очистить журнал** удаляет локальную историю;
- экспорт собирает текущий журнал и архивы в один JSONL.
